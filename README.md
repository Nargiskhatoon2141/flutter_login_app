# 📱 Flutter Login & Student App

A beginner-friendly Flutter mobile application created as a practice project for learning Flutter app development.

This project started with a Login and Sign Up system and was gradually expanded into a small multi-page mobile application with a Home Dashboard, Profile, Courses, Settings, Dark Mode, and About page.

---

## 📌 Project Overview

This application demonstrates the basic structure and concepts of a Flutter mobile application.

The main purpose of this project is **learning by building**.

Instead of creating only a single screen, the application contains multiple connected pages so that important Flutter concepts can be practiced, including:

- Flutter widgets
- StatefulWidget
- StatelessWidget
- `setState()`
- TextFields
- Text controllers
- Buttons
- Navigation
- Passing data between pages
- Callback functions
- Theme management
- Dark Mode
- Reusable widgets
- Grid layouts
- Forms
- Basic login validation

# ✨ Features

## 🔐 1. Login Page

The application starts with a Login screen.

The Login page contains:

- Email input field
- Password input field
- Show/Hide password button
- Login button
- Forgot Password option
- Sign Up option
- Basic login validation
